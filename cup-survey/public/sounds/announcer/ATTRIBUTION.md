# Announcer cue sounds

Short interface cues for the voice announcer (pre-roll chimes).

Built-in MP3 files are committed in this directory. See `lib/announcer/cueCatalog.ts` for ids and labels.

## Sources

| File prefix | Source |
|-------------|--------|
| `universfield-*.mp3` | User-provided notification sounds (Universfield) |
| `chime-*.mp3` | User-provided notification chimes |
| `awesome-notification.mp3` | User-provided (koiroylers) |
| `soft-alert.mp3` | User-provided (miraclei) |
| `deep-ui-chime.mp3` | User-provided (soundshelfstudio) |

Custom uploads via admin UI are stored separately per tournament scope.
